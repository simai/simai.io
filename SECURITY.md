# Security

Please report security problems privately through GitHub's **Report a
vulnerability** (the repository's Security tab), not in a public issue.
Include the page, the commit and how to reproduce it. We answer within five
working days.

In scope:

- a portal page that loads code from anywhere but the pinned Framework
  release or this repository;
- a published page that exposes anything beyond the registry and its content;
- a product link in the registry that leads somewhere other than the product.

Problems in a product itself belong to that product's repository.
